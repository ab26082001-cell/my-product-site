# PaydayMap

GenAI class assignment prototype for a salary-cycle budgeting tool for young professionals in India.

## Deployment
1. Import this repository into Vercel and set the Root Directory to `paydaymap-assignment`.
2. Configure the required server-side environment variables in Vercel.
3. Apply the included Supabase schema in your Supabase project.
4. Generate at least five test plans and capture the deployment/database evidence requested in the assignment.

No API keys are stored in this repository.
